# town_return_heal (CN baseline / English ROM)

New mod. Returning to town through the blue teleporter after a boss, or with an Angel Wing, now
refills HP and SP, the same way leaving the arena already does.

- Definition: `patches/custom/town_return_heal.json` (stage `static_candidate`, evidence `runtime_verified`),
  generated by `translation/tools/make_town_return_heal.py` (assembles the stub, checks preimages).
- Writes: `0x08058488` (4 B, BL retarget) and the stub at `0x080BB1F0` (48 B).
- **Allocation:** `0x080BB1F0..0x080BB21F` (48 B, was zero in CN baseline and English ROM, no
  literal references anywhere in the ROM, no official/custom mod writes there). Owner `town_return_heal`.
- Ship: `Patch_Manager/patches/town_return_heal.ips` (4 records, 49 bytes, against the English ROM;
  applying it reproduces `translation/build/ss2-en+town_return_heal.gba` byte for byte).

## How the game does it (`static_verified` + runtime traces, English ROM = CN baseline here)

- Player stats live in the actor table `0x03003D80`, stride `0x154`; local actor index from
  `0x080020F4`. Fields: `+0x6A` max HP, `+0xCC` HP, `+0x68` max SP ×10, `+0xCA` SP ×10
  (HUD shows value/10). Found by RAM diff over the arena heal (58 → 66 at `0x03003E4C`).
- **Arena exit** heal: per-map script `0x0808FA58` (map script table entry at `0x0851A430`) copies
  `+0x6A → +0xCC` and `+0x68 → +0xCA` at `0x0808FAF4..0x0808FB06`. It is local to that script.
- **warp(area, entry)** `0x0805847C`: zero-extends both args and calls the map loader
  `0x08026C0C(area, entry, 0)`. The area id is at `[[0x03005DB4]]+0`; town = 0. Its 21 callers:
  - 13 per-level boss teleporter scripts, all `warp(0, 2)`: `0x0808D55E`, `0x0808D6F2`, `0x0808D88A`,
    `0x0808DD9E`, `0x0808E3A6`, `0x0808E61A`, `0x0808E7AE`, `0x0808EBBA`, `0x0808EF2A`, `0x0808F29E`,
    `0x0808F342`, `0x08090018`, `0x080904DC`. (Post_Boss trace: area 1 → 0 via `0x0808D55E`.)
  - Angel Wing beam-out (in the function ending `0x0806414C`, plays sound `0x75`): `warp(0,0)` at
    `0x08064130` (normal; Angel_Wing trace: area 4 → 0 via it), `warp(0,4)` at `0x080640FC` when actor
    `+0x38 & 0x2000` (the flag the arena script clears), and `warp([+0x34],[+0x32])` at `0x080640DA`
    when `0x0800C61C()` is nonzero.
  - `warp(0,0)` in other level/event scripts: `0x0808FC2A` (arena script, other branch), `0x080901B6`, `0x08090656`.
  - Not town: `0x0808B2C6` `warp(0xD,0)`, `0x08067CE0` `warp([+0x34],[+0x32])`.

## The patch

`bl 0x08026C0C` at `0x08058488` becomes `bl 0x080BB1F0`. The stub:

```
cmp r0,#0 ; bne go            ; area != town: untouched
push {r0,r1,r2,lr}
bl 0x080020F4                  ; local actor index
actor = 0x03003D80 + idx*0x154
+0xCA = +0x68 ; +0xCC = +0x6A   ; same copies as the arena script
pop {r0,r1,r2,r3} ; mov lr,r3
go: ldr r3,=0x08026C0D ; bx r3  ; tail call, returns to 0x0805848D
```

ARMv4T Thumb only; r0–r2 are preserved for the loader, r3 is clobbered (the loader takes 3 args,
and callers such as `0x08064116` leave r3 arbitrary). Stack stays 8-byte aligned.

Scope: every `warp()` to town heals, so it also covers the Angel Wing variants and the other
scripted town returns listed above, not just the two cases asked for. Warps that do not go
through `0x0805847C` (e.g. `0x08064116` calling `0x08026C0C(0xB,0,1)` directly) are unaffected.
Status ailments are not touched (the arena heal doesn't touch them either).
