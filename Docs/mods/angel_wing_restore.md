# angel_wing_restore (CN baseline / English ROM)

New mod, two changes:

1. Using an **Angel Wing** sets HP and SP to their maximum instead of returning you to town. It
   works when either HP or SP (or both) is missing. With both full the game refuses it with the usual
   "can't use" buzz and you keep the wing, the same as a Herb at full HP.
2. **Only one Angel Wing may leave town.** When you leave town for anywhere except the arena,
   the bag keeps its first Angel Wing and every other one is deleted. With
   stackable_consumables, a stack is cut to ×1.

- Definition: `Patches/Definitions/Custom/angel_wing_restore.json` (stage `runtime_verified`),
  generated by `Patches/angel_wing_restore/build.py` (assembles, checks every preimage).
- Ship: `Patch_Manager/patches/angel_wing_restore.bps` and `cn/angel_wing_restore.bps` (CN-compatible).
- **Writes / allocation:**
  - `0x0805C60E..0x0805C639` (44 B): in-place rewrite of the effect-4 branch. The old branch's
    remaining bytes up to `0x0805C6D7` are left as unreachable dead code.
  - `0x08026C0C` (8 B), `0x08022D78` (8 B): entry hooks `ldr r3,[pc,#0]; bx r3; .word stub|1`.
  - `0x09018000..0x090180FF` (owner `angel_wing_restore`, zero in the baseline, 156 B used): the two
    entry stubs and `purge(area)`.
- No byte overlap with any definition (`mod_conflicts.py`) or with any of the 33 other shipped
  patches in `Patch_Manager/patches/` (decoded against the English ROM).

## How the game does it (English ROM = CN baseline here, traced)

- **Consumable records**: bag item type 1 → record table `0x083DCEBC`, stride `0x184`.
  Angel Wing is code 6. The fields used:

  | Field | Meaning |
  |---|---|
  | `+0x174` | price |
  | `+0x178` | effect type: 1 = HP, 2 = SP, 3 = antidote, 4 = Angel Wing, 5 = Soul Return, 6–9 = stat foods, 0x11 = full HP+SP (unused by the base items), 0x12 = HP without the "can't use" check |
  | `+0x17A` | amount |

  The generic record getter is `0x080069C0(type<<16 | index, table)`, and `0x08006D98` is its
  wrapper.
- **Use-item** `0x0805C3B8(item*, arg)`: r5 = local player actor
  (`0x03003D80 + idx*0x154`), and it switches on `+0x178`. A fail jumps to `0x0805C85C`
  (sound `0x61`, returns 0, the menu keeps the item). Success goes through `0x0805C864`
  (returns 1). HP heals end in a tail at `0x0805C81C`: the sparkle `0x08075590(id, 8)` when the
  amount is non-zero, then it clears the low-HP flag (`+0x38` bit 17) when HP ≥ max/2, plays sound
  `0x91`, then succeeds.
  - Effect 4 (`0x0805C60E`) refuses in town (bit 3), in the arena, and in some other states.
    Otherwise it plays `0x75`, sets action `+0x26 = 0xC` and calls `0x08015614`. The animation's
    event 1 (`0x08011C68`) then starts the "death" task `0x08063C84` through `0x08065DF0(id, 0)`.
    Without the death flag (`+0x38` bit 13), that task does `warp(0,0)` at `0x08064130`. So the
    Angel Wing beam-out and death share one task.
- Ring menu "use" `0x0807EBAE`: it calls `0x0805C3B8(menu+0xF4, …)`. If that returns 0, the
  menu stays open. If it returns 1 and the item is type 1 code 6, `menu+0x24 = 0` (the menu closes),
  then `0x0807C4DC` removes the item (stackable_consumables hooks that call at `0x0807EC16` to
  decrement its stack). That menu code is unchanged, so after a successful use the menu closes.
- **Leaving town.** Flag `0x03003518` bit 3 = "in town" (see `end_dungeon_on_death.md`).
  Walking out of town opens the world map with area still 0 and bit 3 set. Picking a place calls
  `area_change(dest, 1)` `0x08022D78` from `0x0800C212`. Warps such as the Angel's "back to where
  you died" go through the map loader `0x08026C0C(area, mode, fade)`. Every `warp()`
  (`0x0805847C`) uses it. Other callers: `0x08027B8A`, `0x08064116`. `area_change` is also
  called from `0x08022868` and `0x08027008`. Bag: `[0x03003580]+0x158`, 25 × 16 B.
  stackable_consumables keeps the count at `+4` (0 or 1 = single).

## The patch

Effect 4 becomes:

```
r6 = &SP (+0xCA), r7 = &maxSP (+0x68)
if SP == maxSP && HP == maxHP: b 0x0805C85C        ; refuse, keep the item
SP = maxSP ; HP = maxHP
r6 = &HP, r7 = &maxHP ; bl 0x08075590(id, 8)       ; sparkle
b 0x0805C830                                        ; game's HP-heal tail
```

Both entry stubs save r0–r2/lr, call `purge(r0)`, then replay the 4 overwritten instructions and
jump back. The loader resumes at `0x08026C14`. `area_change` resumes at `0x08022D82`, or at
`0x080230BA` when mode is 0. r3 is free at both entries: neither function takes a fourth argument,
and both write r3 before reading it.
`purge(area)` returns at once when the area is 0 (town) or 0xB (arena), or when bit 3 is clear.
Otherwise it walks the local bag: the first type 1 / code 6 slot stays (its `+4` count is cut to 1
if higher), and every later one gets type 0. That is how the game deletes items.

Scope: this covers every exit from town through the world map or through any map-loader warp.
Dungeon → town, town → town and town → arena are left alone, and so are wings found inside a
dungeon. Only the local player's bag is trimmed. Multiplayer/link was not looked at.

## Runtime A/B (`runtime_verified`, English ROM vs English + mod)

```
Tools/.venv/bin/python Patches/angel_wing_restore/test.py Build/en.gba Patches/angel_wing_restore/ss2-en+angel_wing_restore.gba
```

These are the user's states, driven by visible input. Diagnostic RAM writes are labelled: `fill`
sets HP/SP to max, and `give_wings` puts Angel Wings into the first three empty bag slots, one ×3
stack and two singles (Leaving_Town has none). The output is in
`Patches/angel_wing_restore/test_output.txt`.

| State / input | English | English + mod |
|---|---|---|
| Angel_Wing, A | town, HP 49/66 | **stays in area 4, HP 66/66**, wing used, menu closes |
| Angel_Wing_2, A | town, HP 3, SP 27 | **stays, HP 66/66, SP 86/86** |
| Angel_Wing + `fill`, A | town | **refused** (menu stays on the wing), wing kept |
| Leaving_Town + `give_wings`, down → world map → RIGHT, UP, A | area 3, wings ×3, 1, 1 | area 3, **one wing (×1)** |
| Post_Death_Angel + `give_wings`, A ×8 (Angel: go back) | area 6, wings kept | area 6, **one wing (×1)** |
| Post_Boss + `give_wings`, A (teleporter to town) | town, all wings | town, all wings (unchanged) |

Stacked with `stackable_consumables_104b1_consumefix.ips32` (built with `patch_manager.build`):
using an Angel Wing from a ×3 stack restores HP/SP and leaves ×2. Leaving town trims the stack to ×1
and deletes the two singles.

## Notes and not tested

- The Angel Wing's **description text** (English translation, translation-owned bytes) still
  describes the old effect. Changing it would mean editing the translation.
- Not run: the arena exclusion (town → arena), the CN version in the emulator (the savestates
  are English builds; the CN `.bps` has the same bytes at the same addresses), and a normal save
  followed by a reboot (the mod only changes bag slots and HP/SP, which the game saves itself).
- `town_return_heal` is still compatible (no shared bytes). It no longer fires for the Angel Wing,
  because the wing doesn't warp any more.
- `user_accepted`: not yet.
